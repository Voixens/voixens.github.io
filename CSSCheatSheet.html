CSS Cheat Sheet

Data Type

Description
* Targets everything in html
color Changes the color text of an element
font-size Changes the size of the text of an element
font-family Changes the style of the text
background-color Sets a color behind the element
text-align Aligns text horizontally(left, center or right)
width Sets the horizontal size of an element
height Sets the vertical size of an element
margin Sets the space around the element's border
padding Adds space between element around content
margin Adds space outside the element's border
border Creates a border around an element
border-radius Rounds the corners of an element's border
display Controls layout behaviour
justify-content Used to space or position flex items inside a flex container
flex-direction Determines the direction flex items are arranged in a flex container
