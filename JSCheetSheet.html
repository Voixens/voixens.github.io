Javascript Cheat Sheet

Data Type

Description
let Declares variables and can be reassigned later
const Declares variables but cannot be reassigned
var Older way to declare variables
if statement Runs code if the condition is true
else statement Runs alternative code if the if statement condition was false
for loop Repeats code a number of times
while loop Repeats code while the condition remains true
function A reusable block of code that performs a task
return Sends a value back from a function
document.getElementBy(Id) Selects an HTML element by it's ID
addEventListener Runs code when an event happens
innerHTML Gets or changes the HTML inside an element
console.log() Prints information into the browser console for debugging
Array Stores multiple values in one variable
push() Adds an item to the end of an array
textContent Gets or changes the text inside an element
